# IDEA: Data Import Validation Pipeline

## 背景

取引先から届く CSV や Excel 由来のデータを取り込む時、列名の揺れ、型の不一致、欠損、重複、コード体系の違いで毎回手戻りが出ている。
今は担当者がエラーを見つけて手作業で直しているため、取り込み結果の信頼性が低い。

## 作りたいもの

CSV を読み込み、検証、正規化、エラー分類、取り込み可能なレコードと差し戻しレポートの生成を行うパイプライン。
最初は DB に保存しなくてよく、ローカル fixture とテストで動けばよい。

## 期待していること

壊れた行があっても全体が落ちるのではなく、どの行の何が問題かを分かりやすく出したい。
取り込める行と、修正が必要な行を分けたい。
同じファイルを再実行しても結果を追えるようにしたい。

## 制約・好み

検証ルールと正規化ルールは分けて扱いたい。
最初からあらゆるファイル形式には対応しない。
人間が修正しやすいエラーレポートを重視したい。

## 迷っていること

列名の揺れをどこまで自動補正するかはまだ決めていない。
重複判定のキーは取引先ごとに変わるかもしれない。
将来はバッチや Web API から使う可能性がある。
