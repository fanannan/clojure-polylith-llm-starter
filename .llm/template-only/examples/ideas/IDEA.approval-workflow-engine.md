# IDEA: Approval Workflow Engine

## 背景

社内の申請や承認がメールとチャットで流れていて、誰がどの状態で止めているのか分かりにくい。
差し戻し、代理承認、期限切れ、監査ログが絡むと、後から経緯を追うのが大変になっている。

## 作りたいもの

申請、承認、差し戻し、却下、取り下げを扱う小さな承認ワークフローエンジン。
最初は UI や認証基盤は不要で、状態遷移と権限チェックをテストで確認できればよい。

## 期待していること

申請が今どの状態にあり、次に誰が何をできるのかを明確にしたい。
不正な遷移は受け付けたくない。
承認や差し戻しの履歴は、あとから監査できるようにしたい。

## 制約・好み

状態遷移のルールはコード上で追いやすくしたい。
通知やメール送信は最初は実装しなくてよいが、期限切れやリマインドの余地は残したい。
特定の組織階層や人事システムに固定したくない。

## 迷っていること

承認者の決め方は部署や金額で変わるかもしれない。
代理承認をどこまで扱うかはまだ決めていない。
将来は Web API から使いたいが、最初から大きな SaaS にしたくない。
