# IDEA: Subscription Billing Engine

## 背景

小さな SaaS の料金計算を、スプレッドシートと手作業から移したい。
月額料金、従量課金、割引、日割り、税、上限金額が絡んでいて、毎月の請求確認に時間がかかっている。

## 作りたいもの

顧客の契約プラン、利用量、期間、割引条件から、請求明細を生成する小さな料金計算エンジン。
最初は外部決済サービスや DB 連携は不要で、ローカルのデータとテストで動けばよい。

## 期待していること

同じ入力なら同じ請求明細が出るようにしたい。
プラン変更や月途中の解約がある月でも、計算根拠を追えるようにしたい。
上限金額や最低利用料があるプランでも、なぜその金額になったかを説明できるようにしたい。

## 制約・好み

料金ルールはなるべく純粋関数として扱いたい。
最初から管理画面や認証は要らない。
将来、Web API やバッチ処理から同じ計算ロジックを呼べる形にしたい。

## 迷っていること

税率や丸め方法はまだ確定していない。
割引の種類は増えそうなので、後から拡張できる余地はほしい。
ただし、最初から複雑な rule engine にはしたくない。
